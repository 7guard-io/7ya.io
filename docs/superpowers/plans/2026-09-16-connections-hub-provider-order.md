# Provider connection order

Connect sources by expected value to Igor Core, not by platform prestige.

1. YouTube — durable original video corpus, dates, thumbnails and view metrics.
2. Instagram — current personal visual/reel corpus.
3. Facebook — long historical post/video/repost corpus.
4. TikTok — viral video/LIVE corpus and distribution metrics.
5. LinkedIn — professional/public-service history and posts.
6. X — posts/mentions.
7. Threads — posts/conversations.
8. Telegram — direct distribution archive.
9. Vercel — only after content connections; infrastructure must not block corpus work.

Already-known infrastructure/measurement connections remain visible but do not consume connection priority: GitHub Canon, Google Search Console, GA4, Google Drive, AppDeploy legacy.
