## Launch principles

- Human first.
- Evidence before amplification.
- Visual richness must come from real public media, not one repeated portrait.
- Metrics require dated exports or screenshots.
- Personal narrative, institutional proof, public distribution and aspiration remain separately classified.
- Children, private family details, legal/financial material and operational information remain protected.

## Release action

This commit intentionally triggers the guarded GitHub Pages workflow so the complete current `main` artifact replaces the older custom-domain deployment on `7ya.io`.

The deployment is accepted only after the workflow passes `npm run release:gate` and the public domain serves the updated homepage, journey, archive, StartOn, evidence and release metadata.
