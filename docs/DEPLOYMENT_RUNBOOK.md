# 7YA.IO Deployment Runbook

## Approved production path

- Repository: `7guard-io/7ya.io`
- Default branch: `main`
- Workflow file: `.github/workflows/pages.yml`
- Workflow name: `Publish 7YA Production Site`
- Trigger: manual `workflow_dispatch`
- Target: GitHub Pages
- Domain: `https://7ya.io`
- Release mode: full-site static
- Artifact directory: `dist/`

## Pre-deployment requirements

1. Confirm repository and default branch.
2. Confirm the production workflow file, name and target have not changed.
3. Read `docs/RELEASE_STATE.json`.
4. Check issue `#83` and other open blockers.
5. Confirm the intended commit is on `main`.
6. Review the final diff.
7. Run `node scripts/check-site.mjs`.
8. Run `node scripts/check-links.mjs`.
9. Assemble the exact production artifact locally using the workflow copy contract.
10. Run `node scripts/inject-ga4.mjs dist` and verify complete HTML coverage.
11. Record the previous known-good commit as rollback point.
12. Confirm explicit approval exists before any workflow run.

## Full-site source validation

Verify:

- `CNAME` contains exactly `7ya.io`.
- `index.html` is the Igor-first homepage.
- `index.html` contains `index, follow` and the canonical `https://7ya.io/` URL.
- `index.html` and `404.html` contain no external meta refresh or JavaScript redirect.
- `scripts/inject-ga4.mjs` exists.
- The critical route files exist:
  - `journey/index.html`
  - `igor-vepretski/index.html`
  - `starton/index.html`
  - `evidence/index.html`
- Required styles and portrait assets exist.

## Artifact assembly contract

The site is not generated by `npm run build`. Assemble it as follows:

```bash
set -euo pipefail
rm -rf dist
mkdir -p dist

cp index.html \
   404.html \
   CNAME \
   robots.txt \
   sitemap.xml \
   favicon.svg \
   sw.js \
   service-worker.js \
   dist/

for path in \
  styles evidence journey starton oracle business talk contact \
  speaker media 7ya igor-vepretski influence social articles \
  pass radar member-pass data assets images
do
  if [ -e "$path" ]; then
    cp -RL "$path" dist/
  fi
done

touch dist/.nojekyll
```

After assembly, verify at minimum:

```bash
test -f dist/index.html
test -f dist/journey/index.html
test -f dist/igor-vepretski/index.html
test -f dist/starton/index.html
test -f dist/evidence/index.html
test "$(cat dist/CNAME)" = "7ya.io"
```

## Analytics contract

Run:

```bash
GA_MEASUREMENT_ID=G-1028S7MMGQ node scripts/inject-ga4.mjs dist
```

The number of HTML files in `dist/` must equal the number containing the approved Google tag. A conflicting measurement ID or incomplete coverage is a hard failure.

## Publishing steps

1. Open GitHub Actions for `7guard-io/7ya.io`.
2. Select `Publish 7YA Production Site`.
3. Confirm the file is `.github/workflows/pages.yml`.
4. Confirm the selected ref is `main`.
5. Confirm the approved commit SHA and rollback SHA are recorded.
6. Run the workflow once through `workflow_dispatch`.
7. Confirm validate, assemble, analytics, configure, upload and deploy steps succeed.
8. Save the workflow run identifier and logs when available.
9. Do not retry blindly if issue `#83` prevents the job from starting.

## Post-deployment verification

1. Open `https://7ya.io` in a clean browser context.
2. Confirm Igor Vepretski is visible above the fold.
3. Confirm no redirect to Vercel, Netlify or the Digital Museum host occurs.
4. Test mobile and desktop.
5. Verify the critical routes and the public route set in `docs/RELEASE_STATE.json`.
6. Confirm canonical URLs and robots directives.
7. Confirm GA4 appears once per HTML response where artifact injection applies.
8. Save screenshots and route results.
9. Archive commit, workflow result and rollback point.

## Forbidden deployment paths

Do not publish through ZIP upload, temporary hosting, obsolete repositories, Vercel, Netlify, local manual replacement, Datasite, unverified workflows or automatic triggers while issue `#83` remains unresolved.

## Required report

Report production status, branch, files changed, tests, PR and commit, workflow result, live routes verified, archived evidence, blockers and exact rollback point.
