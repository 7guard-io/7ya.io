# STYLING RULES & TAILWIND CONFIGURATION

- **Theme:** Strictly Dark Mode.
- **Allowed Palette:**
  - Backgrounds: `bg-black`, `bg-gray-900`, `bg-gray-800`
  - Text: `text-white`, `text-gray-300`, `text-gray-400`
  - Primary Accent (Cyan): `text-cyan-400`, `bg-cyan-500`, `border-cyan-500`
  - Alert/Secondary (Orange): `text-orange-400`, `bg-orange-500`
- **Prohibited:** No white backgrounds, no blue/red/green generic colors. Do not write custom CSS, use exclusively Tailwind utility classes.
