# Connections Hub UI contract

Each card must answer five questions without opening another page:
1. What source is this?
2. Is it usable now?
3. Through which route (Direct / Metricool / Windsor / Legacy)?
4. What enters Igor Core from it?
5. What is the one next action?

Missing OAuth sources use a copyable ChatGPT command, not a stored OAuth URL. The live OAuth URL is generated only when the user chooses that source in chat.
