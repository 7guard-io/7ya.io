# Tests

## Test 1 - Canonical documentary homepage keeps the major public rooms discoverable [sanity]
Viewport: desktop
Covers: documentary homepage, Igor-first hero, Media, Research, StartOn, Evidence, Library, source-linked visual proof
Description: Verifies the consolidated home remains one coherent entry point into the living archive instead of fragmenting the product into competing mini-sites.
Steps:
1. Open /?lang=he and confirm the Igor hero, the personal story CTA and at least one source-linked visual/media section are visible
2. Confirm Media, Research, StartOn, Evidence and the full archive/library remain reachable from the visible home navigation or CTAs
3. Open Media and return to the homepage
Expected: The homepage reads as one documentary experience, major rooms remain discoverable, and navigation does not require a legacy ?page= URL to function.

## Test 2 - Legacy query route normalizes even when opened on the wrong clean path
Viewport: desktop
Covers: canonical routing, legacy ?page= compatibility, locale preservation, split-brain prevention
Description: Verifies stale or malformed links cannot render one room under another room's canonical pathname.
Steps:
1. Open /media/?page=research&lang=en
2. Wait for route normalization
3. Confirm the Research experience is visible
Expected: The browser URL is /research/?lang=en, the page query parameter is removed, and Research is not rendered under the /media/ pathname.

## Test 3 - Canon search survives a coverage endpoint failure
Viewport: desktop
Covers: /search/ canonical results, independent coverage loading, graceful degradation, Public Discovery independence
Description: Verifies an optional coverage failure does not blank otherwise valid canonical search results.
QA Faults:
```json
[
  {
    "method": "GET",
    "path": "/api/graph/coverage",
    "status": 500,
    "body_json": {"error":"simulated_coverage_failure"}
  }
]
```
Steps:
1. Open /search/?lang=he&q=StartOn
2. Wait for the canonical search request to complete
3. Inspect the results area and the coverage area
Expected: Canonical search results or a valid canonical empty state remain usable, Public Discovery can continue independently, and the page does not show the global search-failed state solely because coverage failed.

```json
  }

```

3. Inspect the canonical results section and the Public Discovery section

Viewport: mobile
Covers: mobile hero, CTA wrapping, source-linked visual proof, clean-route navigation, horizontal overflow guardrail, persistent-control collision guardrail
Description: Performs a strict mobile review of the consolidated documentary home.
Steps:
1. Open /?lang=he and inspect the hero headline, portrait/background crop and primary CTA in the first viewport
2. Scroll through the first source-linked visual/media section and open Media or the archive from a visible clean-route CTA
3. Return to home and continue through the first two content sections
