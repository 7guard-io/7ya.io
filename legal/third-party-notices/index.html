Third-party notices for 7YA.

This page keeps open-source attribution visible, separated from marketing claims, and tied to the actual repository dependencies.

Open notice register Back to links

Source of truth

The notice register is based on package.json and package-lock.json, with a local generator at scripts/generate-third-party-notices.mjs.

Operating rule

Only dependencies actually present in this repository belong in the 7YA notice register. External notice bundles are reference patterns, not proof of use.

Release gate

  • Regenerate after dependency changes.
  • Review packages with missing license metadata.
  • Keep required copyright, license, and NOTICE text.

Command

npm run legal:third-party

This rebuilds the notice register from the current lockfile.
