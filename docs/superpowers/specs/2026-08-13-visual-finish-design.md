# 7YA Visual Finish Design

## Goal
Finish the public 7YA experience as a personal, premium, media-rich flagship while preserving integrity, multilingual access, and source-linked evidence.

## Approved experience
The homepage follows one deliberate sequence: personal hero → real media/posts → Igor story → StartOn mission → public media/evidence → Digital Igor companion → closing action.

## Visual direction
Use a restrained cinematic editorial system: dark graphite hero, warm paper surfaces, amber signal color, electric-blue secondary accent, strong portrait photography, large typographic hierarchy, asymmetric media grids, generous whitespace, subtle motion, and no collage-style composites. Individual media items remain distinct cards/frames.

## Scope
1. Refine the homepage hero so Igor is unmistakably the primary subject within the first viewport.
2. Make the first media section feel like a living editorial feed rather than a dense archive.
3. Improve mobile hierarchy, spacing, image cropping, and CTA clarity.
4. Keep StartOn, evidence, and Digital Igor as separate high-signal chapters.
5. Preserve HE/EN/RU, crawlability, source links, and claim-safety constraints.
6. Establish a single release marker for the completed AppDeploy build.

## Non-goals
No new product subsystem, billing flow, authentication redesign, data migration, or speculative claims. No removal of evidence surfaces.

## Acceptance criteria
- Desktop and mobile render without frontend/backend/network errors.
- E2E terminal status is passed.
- #posts-first is visually present and inspectable in QA evidence.
- Hero, media feed, StartOn, evidence, and Digital Igor have clearly differentiated visual chapters.
- Mobile has no horizontal overflow, crushed typography, or stacked CTA ambiguity.
- Live root and release metadata identify the same completed release marker.
