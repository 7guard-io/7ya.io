## Scope
This directory is an audit snapshot for the 7YA TOTAL REALITY foundation release. The production source tree is managed by AppDeploy and is not identical to the GitHub repository root. This snapshot therefore records the release explicitly rather than pretending the two trees are the same.

Key runtime changes in this release family:
- `RealityIndex` homepage layer derived from the canonical graph.
- URL-filterable canonical search and domain deep links.
- Legacy public-register → canonical-corpus adapter with URL dedupe and evidence-safe date/metric handling.
- Canonical People / Places / Institutions entity layer.
- Public `/api/entities` retrieval endpoint.
- AI `search_entities` tool plus graph relationship traversal.
- People / Places / Institutions atlas linked back to canonical moments.
- Coverage Engine now reports People and Places from first-class canonical entities instead of artificial zero placeholders.
- Release metadata no longer reports old E2E results as current.
